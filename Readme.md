## 🚀 How to Use

1. **Clone the repository:**

   ```bash
   git clone https://github.com/KanishkRajTech/LeetCode-SQL.git
   cd LeetCode-SQL
   ```

2. **Navigate to any problem folder** and open the `.sql` file.

3. **Copy the query** into the LeetCode editor or your local MySQL workbench and run it.
